# Flight Compass

Design and build a premium, modern, highly polished and visually distinctive flight booking marketplace website.
The goal is to create a real product experience, not a generic airline website, travel agency template, or dashboard template.
The platform helps users discover and book affordable flight offers.
IMPORTANT:
This is NOT an airline.
This is NOT a traditional airline website.
This is a modern flight ticket marketplace where flight offers are managed by the platform administration and displayed to customers.
The design should feel like a premium travel-tech startup: elegant, intelligent, trustworthy, modern, minimal, and slightly futuristic.
Avoid generic travel website layouts, excessive gradients, cartoon illustrations, or overly colorful UI.
DESIGN DIRECTION
Create a clean and sophisticated visual identity inspired by premium SaaS products, modern fintech interfaces, and high-end travel platforms.
The design should feel:
Premium
Minimal
Modern
Trustworthy
Fast
Intelligent
International
Elegant
User-friendly
Use generous whitespace and strong visual hierarchy.
The interface should feel expensive and professionally designed.
Avoid making it look like a WordPress travel template.
Use subtle animations and micro-interactions.
Cards should have refined borders, soft shadows, and elegant hover states.
Use rounded corners, but avoid excessive roundness.
The visual system should be consistent across all pages.
COLOR SYSTEM
Use a sophisticated travel-inspired color palette.
Primary color:
Deep navy or midnight blue.
Secondary accent:
Electric blue or a refined cyan.
Background:
Very light neutral gray or soft off-white.
Cards:
White.
Text:
Dark navy or near-black.
Use accent colors carefully for:
Prices
Important actions
Status indicators
Active selections
Avoid excessive use of bright colors.
The final design should feel premium and calm.
TYPOGRAPHY
Use a modern, highly readable sans-serif font.
Create strong hierarchy between:
Page titles
Section titles
Flight information
Prices
Secondary information
Flight prices should be visually prominent.
Important travel information should be easy to scan quickly.
WEBSITE STRUCTURE
Create the following user-facing pages.
1. Homepage
The homepage should immediately communicate:
"Find your next flight at a better price."
Create a large premium hero section.
The hero should include a sophisticated flight search interface with:
From
To
Departure date
Return date
One-way / Round-trip
Number of passengers
Travel class
Search button
The search component should be the visual centerpiece of the page.
Below the hero, create:
Cheapest Flights
Display a curated grid or horizontal layout of attractive flight offers.
Each flight card should include:
Departure city
Destination city
Airline
Departure date
Flight duration
Number of stops
Price
Clear "View Flight" action
The cards should feel modern and premium.
Do not use generic stock-card designs.
Create a visual system that makes the route itself feel important.
For example:
DAM → IST
with an elegant visual flight path or directional line.
2. Search Results Page
Create a highly polished flight search results experience.
Layout:
Left side:
Filter panel.
Filters include:
Price range
Airlines
Number of stops
Departure time
Arrival time
Main area:
Flight result cards.
Each result should clearly display:
Airline
Airline logo placeholder
Departure time
Arrival time
Airports
Duration
Stops
Baggage
Price
Last price verification
Select Flight button
The information should be extremely easy to scan.
Use strong typography and spacing.
Do not overload the user with unnecessary visual elements.
The selected or recommended flight can have a subtle visual highlight.
3. Flight Details Page
Create a premium flight details experience.
The page should clearly present:
Route
Airline
Flight number
Departure information
Arrival information
Flight duration
Stops
Baggage
Travel class
Total price
Create a visual journey timeline between departure and arrival.
The booking summary should be displayed in a sticky sidebar or floating card on desktop.
Include:
Price
Number of passengers
Important information
Continue to Booking button
The user should feel confident and informed before booking.
4. Booking / Passenger Information Page
Create a clean multi-step booking experience.
Use a progress indicator.
Example:
Flight
Passengers
Payment
Confirmation
The current step should be visually clear.
Create forms for passenger information.
The layout should feel simple and secure.
Avoid long overwhelming forms.
The flight summary should remain visible.
5. Payment Page
Create a secure and professional payment experience.
Display:
Booking summary
Total price
Selected payment method
Support UI placeholders for:
Sham Cash
International payment methods
Clearly communicate the current payment status.
The page should visually communicate trust and security.
6. Order Confirmation Page
Create a satisfying confirmation experience.
Show:
Booking successful.
Display:
Booking reference
Flight information
Passenger information
Payment status
Current order status
Add a clear action to:
View My Booking.
7. My Bookings
Create a user dashboard for bookings.
The user should see:
Upcoming bookings
Completed bookings
Cancelled bookings
Each booking card should display:
Route
Date
Airline
Status
Price
View Details
Use clear status indicators.
The dashboard should be simple and elegant.
8. Authentication
Create:
Login page
Sign up page
Forgot password page
Keep these pages minimal and premium.
Use subtle travel-inspired visual elements.
Do not use generic illustrations.
RESPONSIVE DESIGN
The website must be fully responsive.
Design carefully for:
Desktop
Tablet
Mobile
On mobile:
Search should remain easy to use.
Flight cards should be optimized for small screens.
Important actions should remain accessible.
Filters should open in a clean modal or bottom sheet.
The mobile experience should feel like a native travel application.
USER EXPERIENCE
Prioritize usability.
A user should be able to:
Search for a flight.
Compare available offers.
View flight details.
Enter passenger information.
Select a payment method.
Complete the booking.
Track the booking status.
The complete journey should feel simple and frictionless.
COMPONENT SYSTEM
Create a consistent reusable design system.
Include:
Buttons
Inputs
Date pickers
Passenger selector
Flight cards
Status badges
Price components
Filter controls
Booking summary cards
Navigation
Footer
Modals
Empty states
Loading states
Use reusable components instead of designing every page independently.
NAVIGATION
Create a modern top navigation.
Include:
Logo
Flights
My Bookings
Help
Language selector
Login / Account
The navigation should be elegant and minimal.
Consider a transparent navigation over the hero section that transforms into a solid background when scrolling.
IMPORTANT DESIGN RULES
Do NOT create:
A generic airline website
A traditional travel agency template
An outdated booking website
Excessive gradients
Excessive glassmorphism
Cartoon illustrations
Overly colorful UI
Generic dashboard cards everywhere
Excessive rounded elements
A cluttered interface
Instead, create a memorable and distinctive travel product.
The design should feel like a combination of:
Premium travel platform + modern SaaS product + fintech-level clarity.
The website should be visually impressive enough to be used as a professional portfolio project and potentially developed into a real commercial product.
Focus heavily on:
Exceptional visual hierarchy
Premium UI details
Clear flight comparison
Smooth booking flow
Trust
Simplicity
Modern interactions
Create the complete user-facing website design with realistic placeholder flight data.
Do not create the admin dashboard yet.
Focus only on the customer-facing website.
